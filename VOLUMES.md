# Data volumes

The 6 archives below are attached to the GitHub release of this repository (`https://github.com/testimony-anon/testimony-artifact/releases/download/v1.0-review/<volume>`); the anonymized mirror shows the repository files only, so download them from the release links in the table. Extract every volume into the package root (the archives contain paths relative to it), e.g. `zstd -dc volumes/vol1-mainline-runs-conduit-rwa.tar.zst | tar -xf - -C <package root>` (works with GNU tar and macOS bsdtar); then run `python3 scripts/relocate.py`. Volumes 1-3 hold the runs of Conduit and RWA, volumes 4-6 the runs of Umami, Paperless-ngx and Ghost; every volume is independent, so a reviewer who only wants one research question or one subject can download the matching archives.
